# Daily Strategy Journal

The monthly files in this directory are the chronological audit record of the strategy.

Each 17:00 HKT run appends one dated section to `YYYY-MM.md`.

Every entry must contain:

1. Run timestamp HKT / ET and US session.
2. Latest completed RTH date.
3. Six production-file SHAs.
4. Source status, feed and retry outcomes.
5. SOXX formal model metrics and state.
6. SPY/SSO and QQQ/QLD lifecycle state.
7. SMH contextual confirmation/contradiction.
8. Any OPEN / EXIT event and the exact rule that caused it.
9. Actual observed vehicle and 1x benchmark prices used.
10. Leveraged return, 1x return and excess return.
11. Validation / contrary evidence.
12. State/ledger/repository writes made during the run.
13. Methodology version.

The journal records strategy actions only. It is not a record of the user's real brokerage activity and must never contain user account data or real broker orders.
